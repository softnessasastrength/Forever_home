# Renderings

Concept visualizations for the Forever Home. These are **design intent images**, not construction drawings.

Equipment and dimensions in these historical images can be superseded by approved decisions. In particular, do not copy the living flat-screen/faux-fire stack or an island range into the current model. Current direction is a visible cabinet rear-projection TV with a separate pellet hearth, and an appliance-free kitchen island with perimeter induction range/sink/dishwasher. The [measured schematic proposals](../Architecture/Schematic_Study_2026-10-25/README.md) are separate geometric studies; no new rendering or final layout is implied.
