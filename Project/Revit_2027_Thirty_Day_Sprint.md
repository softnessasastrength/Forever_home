# Revit 2027: 30-day production sprint

Date: 2026-10-25
Status: proposed sprint plan based on owner's 30-day Revit 2027 trial; exact trial expiry date to verify.

## Objective
Use limited Revit access to establish a coherent, architect-review-oriented BIM source model for Forever Home. Prioritize architectural geometry, room coordination, essential systems space planning, documentation, and durable exports. VR polish follows later.

## Milestones
- **Days 1–3:** Confirm design brief, vision-preservation priorities, room program, model template, levels and preliminary site assumptions.
- **Days 4–8:** Model footprint, levels, walls, floors, roof, major openings and stair strategy.
- **Days 9–13:** Coordinate rooms, doors, windows, circulation and furniture/equipment envelopes.
- **Days 14–18:** Resolve kitchen and bathroom geometry, accessibility pathway, major room conflicts.
- **Days 19–23:** Reserve and coordinate MEP/technology spaces, primary routes and equipment access. Initial export by Day 21.
- **Days 24–27:** Sections, elevations, schedules, dimension checks, code issue register and coordination review.
- **Days 28–30:** Correct high-priority issues; final export and backup verification.

## File preservation
- Keep native `.rvt` model(s), versioned backups, linked asset inventory and relevant family files.
- Export open IFC format where supported; verify geometry and metadata in an independent viewer.
- Export PDF drawing sheets, DWG/DXF as useful, room/door/window/equipment schedules to CSV, and selected geometry to interchange formats for later Blender/Unreal workflows.
- Validate exports before trial ends; never assume a file exists or imports correctly without checking.
- Keep GitHub for design decisions, specs and small text-based schedules; avoid committing enormous binary models without a deliberate repository storage strategy.

## Modeling priorities
- Favor disciplined BIM categories, coordinates, units, levels, room naming and parametric families.
- Model large equipment and required clearances as envelopes before high-detail objects.
- Distinguish conceptual assumptions from verified engineering.
- Do not claim professional certification, code approval or permit readiness.
