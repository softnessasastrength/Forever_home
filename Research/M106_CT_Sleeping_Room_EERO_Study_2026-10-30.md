# Connecticut sleeping-room emergency escape opening study

Checked: **2026-10-30**

Status: **preliminary statewide code research for schematic design; not a code review**

## Published state basis

Connecticut DAS's current regulations page identifies the 2022 Connecticut State Building Code (CSBC), based on the 2021 International Codes, as current for permit applications filed from 2022-10-01. DAS's code-adoption page says the anticipated 2026 code effective date was delayed pending Legislative Regulation Review Committee approval. A future project's municipality, permit filing date, room classification and applicable code path remain unknown.

The official 2022 CSBC, Amendments to the 2021 IRC, §R310.1, states that every sleeping room must have at least one operable emergency escape and rescue opening. The opening must open directly to a public way or to a yard or court that opens to a public way. Section R310.2.1 states 5.7 sf minimum net clear opening area, with a 5 sf exception for grade-floor or below-grade openings. Section R310.2.3 limits the bottom of the clear opening to 44 in above the floor, with the stated fixed-platform exception.

This is a design prompt, not a compliance conclusion. The code text does not make a room-block edge an exterior wall or establish that a particular roof window, dormer, product, yard path, sill, clear opening or operation qualifies.

## Implication for M78

M78's hypothetical 38.333333 × 40 ft shell has three rooms programmed as bedroom candidates: U-01 primary bedroom, U-03 hybrid bedroom/office and U-04 guest/third bedroom. For this geometric screen, the rectangular test-shell boundary is treated only as a potential exterior-wall line.

In every one of the five retained route-ranked M78 layouts:

- U-01 contacts the west test-shell edge along a 16 ft room-block side.
- U-04 contacts the east test-shell edge along a 13.666667 ft room-block side.
- U-03 has no test-shell perimeter contact. Its nearest shell edge is 8.166667 ft away, on the south side.

U-03's programmed role is bedroom-capable but its sleeping-room classification remains unverified. If it is intended to be used for sleeping, the current block has no perimeter wall segment for a conventional exterior-wall opening. The design must test a revised room/shell arrangement or independently document another qualifying opening strategy with the applicable building official and design professional. A roof opening is not assumed to comply.
