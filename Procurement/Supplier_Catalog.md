# Supplier catalog

Status: proposed workflow; no suppliers approved.

Record supplier ID, name, trade, contact channel, delivery area, quote validity, return policy, lead time, product documentation and alternative suppliers. Home Depot is a candidate, not an exclusive source. Verify exact SKU, code compliance, compatibility and availability before purchase. Keep personal account details and delivery addresses out of this public repository.

## Purchasing gate

Approved design revision → measured takeoff → comparable quotes → compatibility review → owner approval → order → receiving inspection → invoice reconciliation. Record substitutions in the decision log; never silently replace specified products.
