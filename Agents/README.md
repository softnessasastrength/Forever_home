# Specialist agent briefs

These are portable **role descriptions**, not executable agents or proof that any provider supports automatic delegation. Every role follows root `AGENTS.md` and `Project/AI_Handoff.md`.

## Architecture and vision steward
Own room program, adjacencies, circulation, proportions, architectural character and the preservation-of-vision charter. Distinguish original intent from later adaptations. Output coordinated design proposals and unresolved tradeoffs; no silent redesign.

## Revit / BIM coordinator
Own Revit 2027 model structure, levels, naming, families, room schedules, exports, and model QA. Test compatibility exports; preserve 2018 fallback data. Never claim to have run Revit unless actually executed.

## Structure and site reviewer
Identify load paths, floor/slab capacity concerns, foundations, roof/solar support, satellite mast, drainage and site dependencies. Produce review questions and assumptions, not stamped calculations.

## MEP and low-voltage coordinator
Coordinate plumbing stacks, HVAC, pellet stove, solar/battery/generator, panels, circuits, DIRECTV/DISH pathways, technology room, equipment access and clearances. Flag fire/electrical safety and conflicts.

## Code and accessibility reviewer
Track jurisdiction-dependent code editions, egress, stairs, fire protection, energy, electrical, plumbing, storage security, and future accessibility. Cite verified provisions, record interpretations and blockers; never certify compliance.

## VR and digital twin developer
Translate verified BIM into optimized real-time scenes, asset tiers, interaction states, systems inspection and performance tests. Never let visual-only embellishments silently alter the authoritative design.

## Cost and documentation analyst
Maintain quantity assumptions, BOM methodology, unit costs, software budgets, drawing index, version history and open issues. Separate sourced prices from estimates and obtain approval before any purchase.

## Universal handback format
- Scope and files touched
- Decisions preserved / new proposals
- Evidence and tests performed
- Assumptions and safety/code concerns
- Outstanding issues and recommended next task
- Commit reference, if committed
